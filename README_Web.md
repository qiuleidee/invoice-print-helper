# 发票打印助手 Web 版 (V1.3)

发票打印助手 Web 版是一个基于纯前端架构构建的轻量化工具，旨在让用户无需下载安装任何桌面客户端即可在浏览器中实现复杂电子发票的合并、排版和打印。

## ✨ 核心特性与近期重构说明

在 V1.3 版本中，我们彻底剥离了对 Node.js 以及 Electron 主进程 API 的依赖，实现了 100% 的纯浏览器环境同构渲染：

1. **零后端纯静态架构**
   - 新增了 `web/` 独立目录，所有业务逻辑已迁移为纯前端 JS/HTML/CSS。
   - 彻底移除了后端的 `mupdf` 和文件读写模块，使用 HTML5 `FileReader` 替代本地文件路径访问机制。

2. **自研前端 API 模拟层 (Shim)**
   - 编写了 `electronAPI-shim.js`，通过拦截前端业务发送的事件请求，平滑接管了原本属于 Electron 主进程的文件解析、PDF 重排算法和图片解码。
   - 使得前端旧有的核心业务逻辑文件 `app.js` 能够“无痛”地在浏览器环境运行。

3. **火车票文字丢失（乱码）完美修复**
   - 彻底解决了由于国内火车票、客运发票等未内嵌中文字体，导致前端 `pdf.js` 渲染时变成“空白蓝底”的问题。
   - 将 `pdf.js` 及 worker 升级至 `3.11.174` 版本。
   - 引入了官方的 CMap 字典和标准字体包，配置 `fontExtraProperties: true`，并将下载源从被拦截的 `cdnjs` 切换至了友好的 `unpkg`。

4. **所见即所得 (WYSIWYG) 的精准排版**
   - 修复了“网页端排版界面与实际导出 PDF 样式不符”的问题。
   - 引入了“临时文档硬裁切算法 (TempDoc Clipping)”，在拼版引擎内创建了一张正好等于半页 A4 的临时画布，有效将过长的滴滴发票截断，防止溢出。
   - 彻底对齐了渲染引擎和预览截屏的缩放坐标系参数，告别了因坐标失真导致的拉伸、变形及二维码变扁问题。

## 🚀 部署与使用

Web 版本的部署极其简单。您可以直接下载并解压根目录下的 `Web版发票打印助手_V1.3.zip`：

1. 双击运行包内的 `index.html`。
2. 推荐使用现代浏览器（如 Google Chrome, Microsoft Edge, Safari）。
3. 所有计算（包括发票读取、解析、渲染、PDF 拼版合并）**完全在本地浏览器沙盒中闭环运行**，绝对保障财务数据的隐私与安全。
